# Visual Target Pack

Generated by:

```sh
python3 -B scripts/generate_visual_targets.py
```

These boards are aesthetic-direction targets, not final game assets.
The chosen direction is documented in `VISUAL_TARGET_PACK.md`:
**Bone Cathedral, blood-marked** — gore-pixel revival × HLD slickness,
applied per-mode.

Files:

- `synthesis_showcase.png` — chosen direction in contact (the
  synthesis in motion: persistent floor stains, kill frame, attitude
  poses, boomerang blood-mark accumulation).
- `bone_cathedral.png` — chosen direction at rest (composition mode,
  no contact yet).
- `visual_target_overview.png` — four-direction comparison board.
- `neon_coven.png` — brighter neon alternative (rejected: too much VFX
  competition).
- `ash_chapel.png` — warm, restrained alternative (rejected: too warm,
  too low-contrast).
- `bloodglass_pit.png` — sharper arcade-neon alternative (rejected:
  reads more sci-fi arcade than demonic duel).
